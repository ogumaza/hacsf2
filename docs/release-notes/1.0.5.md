A release with a fix to the SFZ files. A note that a key group cuts now fades out at the game's rate. The MIDI files, SoundFonts and samples stay the same as in 1.0.4. Convert an archive again to get the new SFZ files.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bfsar` files onto `hacsf2.exe`. You can also use a terminal. `hacsf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Hacsf2.app`. Drop archives onto the app in Finder to convert them.

## Fixes

- **SFZ key groups.** A note of a key group ends the group's other notes. The game fades those notes out at release rate 126. Each SFZ region in a key group now has `off_mode=time` and an `off_time` of 28.953 ms. The release curve of the SFZ documentation then falls at the game's rate. sfizz 1.2.3 now fades such a note out over 28.953 ms. It used to cut the note in about 6 ms. A SoundFont's exclusive class has no setting for the fade. The SoundFonts stay as they were.

## Other changes

- **Reports.** A conversion's report no longer says "SoundFont attenuated by 0.0 dB" for a cut too small to show. The files stay the same.
- **A warning.** An archive can keep groups in files beside it. When hacsf2 finds none of those files, the warning lists the places that hacsf2 searched. The list now includes `.sarc` files.
- **The README on SFZ.** The SFZ section names the fade of a key group's notes. The list of sfizz 1.2.3's quirks has two new entries. sfizz pans a mono sample by the sin/cos law and then raises both sides by 3 dB. Every sample of the files is mono. Every region therefore plays 3 dB above the game's level in sfizz. A key group in sfizz never cuts a note of the same key as the new note. The game fades that note out at release rate 126.
- **The libraries.** hacsf2 now builds on seqlib 1.3.0, xsflib 1.6.0 and ntdlib 2.0.0.

## Known limitations

As in 1.0.4. The README now names two more quirks of sfizz 1.2.3: the 3 dB on mono samples and the key struck again. See "Differences from the game" in the README for the full list.
