A maintenance release. hacsf2 converts every sound archive to the same files as 1.1.0.

## Downloads

| File | Contents |
|---|---|
| `hacsf2-1.1.1-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bfsar` files onto `hacsf2.exe`. You can also use a terminal. `hacsf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Hacsf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **Paths outside the code page on Windows.** hacsf2 now runs with UTF-8 as its code page. An archive or a folder whose name the system's code page can't hold, such as a Japanese name on an English system, now opens.
- **The libraries.** hacsf2 now builds on seqlib 1.4.0, xsflib 1.10.0 and ntdlib 3.6.1.
