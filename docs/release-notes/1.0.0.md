First release of hacsf2, a MIDI, SoundFont 2 and SFZ converter for Nintendo Switch sound archives (`.bfsar`). It plays each sequence by the game's rules and records the result. Each sequence gets a MIDI file and a SoundFont with its instruments. The SFZ files add the game's filters. SoundFont can't reproduce those.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.bfsar` files onto `hacsf2.exe`, or use a terminal. `hacsf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS and Linux, follow the build instructions in the README. macOS builds include `Hacsf2.app`. Drop archives onto the app in Finder to convert them.

## What it does

- **Sequence playback.** Follows the nn::atk sound player in WarioWare: Get It Together!'s executable. That covers variables, random arguments, calls, loops, tracks that start other tracks, and four LFOs per track. Playback uses the game's 5 ms timing, the Switch audio renderer's handling of note starts and one-shot waves, and the game's random generator. The MIDI file marks the main loop. A loop that sounds nothing gets no markers, and the sequence ends with its last sound.
- **MIDI.** Each sequence track gets a MIDI track. Volume, pan, pitch bend, LFO depth, effect sends and filter changes become controllers. Sends that reach the game's mix dry become part of the level. A note whose pitch or level differs from that of the other notes sounding on its track goes on another channel.
- **SoundFont.** Each combination of instrument and track settings becomes a preset, with the game's samples, tuning, volumes, envelopes and loops. Output targets FluidSynth.
- **SFZ.** One file per sequence track, with the game's low-pass, high-pass and band-pass filters at the renderer's 48 kHz, and WAV samples. Output targets sfizz 1.2.
- **Archives.** Reads Switch FSAR archives, whatever their extension, with PCM8, PCM16 and DSP-ADPCM waves, including banks and wave archives stored in groups. hacsf2 also finds the group files that some games keep beside the archive. hacsf2 reports an unreadable archive and goes on with the others. Archives from other consoles are refused with a message that names the console.
- **Options.** `--loops` repeats the main loop. `--only` selects the sequences. `--seed` sets the random generator. `--var` sets a variable before each sequence starts, for sequences that play nothing until the game sets one.
- **Reports.** Lists the approximations that MIDI, SoundFont or SFZ require for each sequence.

## Known limitations

- Streamed music and wave sounds are not converted.
- MIDI pitch bend applies to a whole channel. When a track runs out of channels, game sweeps, portamento and legato key changes can no longer follow each note.
- A legato with changed envelope or LFO settings starts a new MIDI note. The new note restarts the sample and envelope. The game continues both.
- SoundFont has one low-pass filter per voice. High-pass and band-pass are omitted, and the track low-pass is approximated. The SFZ files have all of these filters.
- Only a track's first LFO is converted. The converted LFO is a sine.
- The synth's reverb stands in for the game's effect on effect bus A.
- When the game runs out of voices, it cuts release tails short. The synth plays them out.
- Interpolation and output limiting in the synths differ from those of the Switch's audio renderer.
- See "Differences from the game" in the README for the full list.
