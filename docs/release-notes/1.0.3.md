A maintenance release. One fix keeps a rare late note-off from hanging a note in a player that loops. The README says more about the main loop and the search for group files.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bfsar` files onto `hacsf2.exe`. You can also use a terminal. `hacsf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Hacsf2.app`. Drop archives onto the app in Finder to convert them.

## Fixes

- **A note-off on a loop marker.** The Switch can defer a note-off past the frame in which it falls. Rounded to the nearest MIDI tick, such a note-off could land on the tick of the loop's end marker. A player that loops at the marker skipped it. The note then hung through the next pass. A note-off before a marker now stays at least a tick before it.

## Other changes

- **Group files in SARC archives.** A game can keep its group files in SARC archives under other names. The README now says that hacsf2 looks for a missing group in the `.sarc` files beside the archive too. hacsf2 takes a group file from a SARC only if its files are of the kinds that the archive gives them.
- **The main loop.** The README's account of the main loop now describes inner loops. A loop that a track runs inside a pass of another loop is an inner loop. Its passes don't qualify until the track has played no pass of another loop for 10 seconds. The README also says that a tie or mono legato on a note below hearing changes nothing that can be heard.
- **SoundFont padding.** A sample's unrolled loop is followed by 32 samples, not 8 as the README said.
- **The libraries.** hacsf2 now builds on seqlib 1.2.0, xsflib 1.3.0 and ntdlib 1.8.0. The README's build section shows how to clone them.
